# Slow Shine

«Мой зимний набор» — страница Slow Shine by Nataly. Статический HTML с локальными изображениями, без зависимостей и фреймворков.

## Локальный запуск

Нужен Node.js 20 или новее. Установка пакетов не требуется.

```sh
npm run dev
```

Откройте <http://127.0.0.1:3000>. Для другого порта: `PORT=3001 npm run dev`.

## Сборка

```sh
npm run build
```

Команда копирует `index.html` и `img/` в `dist/`. Исходная страница находится в `index.html`.

## Публикация на Vercel

Импортируйте GitHub-репозиторий в Vercel. Настройки сборки уже заданы в `vercel.json`: команда `npm run build`, каталог результата `dist`, preset Other. После импорта новые коммиты в основную ветку публикуются автоматически.

Либо используйте CLI из каталога проекта:

```sh
npx vercel@latest login
npx vercel@latest --prod
```
